## <svg xmlns="http://www.w3.org/2000/svg" width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="#6366f1" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M1 12s4-8 11-8 11 8 11 8-4 8-11 8-11-8-11-8z"/><circle cx="12" cy="12" r="3"/></svg> Overview

This repository is a **learning resource and portfolio** for Machine Learning. Each module focuses on a single algorithm and covers the full workflow:

- **Data Preprocessing** — cleaning, scaling, and feature engineering.
- **Model Training** — building and fitting the algorithm.
- **Evaluation** — metrics, confusion matrices, and error analysis.
- **Visualization** — insight-driven plots with `matplotlib` and `seaborn`.

Every module ships with a `DataSet/` folder containing the `.csv` datasets and a dedicated `.md` guide explaining the algorithm behind the code.

## <svg xmlns="http://www.w3.org/2000/svg" width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="#6366f1" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><polygon points="13 2 3 14 12 14 11 22 21 10 12 10 13 2"/></svg> Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/Dev-with-Mouzan/Machine-Learning.git
cd Machine-Learning
```

**2. Install dependencies**

```bash
pip install pandas numpy matplotlib seaborn scikit-learn xgboost
```

**3. Launch Jupyter**

```bash
jupyter notebook
```

**4. Explore**

Open any module folder and run the `.ipynb` notebooks — start with the `.md` guide for theory, then follow the implementation.
